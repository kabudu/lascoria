# Lascoria workspace film

Lascoria. Give your agents room to work.

A light spatial workspace opens to a release-dashboard task. Three helper-agent cards appear, linked to their parent by curved connectors. The Sessions and Attention windows float above the canvas. Working indicators show activity on the cards.

A permission request appears in Attention: run the project's tests. The pointer selects Allow once, the request is acknowledged, and the helper continues.

The API task is selected. Its inspector opens the transcript, then the diff. The diff shows a change from fetching all releases to fetching validated releases.

The Evidence tab connects a test result to the captured content and shows that the content is current. Review remains the user's decision.

Model, reasoning effort, task/model/session token use and subscription usage are shown as separate details, available without adding clutter to the map.

Lascoria. Understand. Steer. Review. The spatial coding workspace.
