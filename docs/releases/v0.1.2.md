# Lascoria v0.1.2: Give parallel work room

Lascoria brings your Muse Code sessions into one spatial workspace. Arrange tasks on a live canvas, see what needs attention, and review changes without losing the thread of parallel work.

- **A workspace you can arrange:** move task nodes, follow curved connections, pan, zoom and keep useful panels close.
- **Attention where it matters:** answer questions and permissions, follow progress, and return to retained session history.
- **Projects across folders:** give Muse repository context, use isolated task workspaces, attach files and exchange messages between sessions on the same machine.
- **Review with context:** inspect changes and revision-bound evidence, run bounded tests and hand files to your editor.
- **Your choice of access:** use a Muse subscription first, configure an API key when needed, and inspect reported usage. Optional decision assistance uses your own separate provider keys.

- **Verified macOS packages:** bounded retries handle temporary Apple ticket-service interruptions while invalid signatures or tickets remain refused.

## Install

Choose the installer for your platform from the [Lascoria release page](https://github.com/kabudu/lascoria/releases/latest). Lascoria checks for a compatible Muse Code installation and can help install it. Model access depends on your Muse account or provider configuration.

## Compatibility and limits

The first release targets macOS, Windows and Linux. Windows installers have no publisher certificate, so Windows may show an unknown-publisher warning or block installation under managed security policies. Updater signatures remain mandatory; do not disable Windows protection to install the app.

Closing the window can keep work running or pause it safely. Full app updates pause active work and preserve checkpoints; returning does not automatically replay uncertain actions. Session messages are local to one machine. Usage displays show what Muse reports and keep subscription allowance separate from API billing.

Read the [installation and support guide](https://github.com/kabudu/lascoria/blob/master/SUPPORT.md), [privacy and account behaviour](https://github.com/kabudu/lascoria/blob/master/docs/accounts.md), and [security policy](https://github.com/kabudu/lascoria/blob/master/SECURITY.md).
