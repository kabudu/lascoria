# Lascoria v0.3.0: Review and deliver from your workspace

Follow completed work from its latest check through staging, commit, push and a GitHub pull request, with one next action in the Workspace tab.

- **Guided delivery:** see the next step for an isolated task, run its check, send a failure back to Muse, review staged changes and deliver the resulting commit.
- **Current validation:** checks are tied to the files they ran against, with clear states for missing, changed, interrupted and failed results.
- **Reviewed destinations:** confirm the remote, branch and outgoing commits before pushing, then review the pull request title, description, base branch and draft setting.
- **Recoverable delivery:** reconcile uncertain push and pull request outcomes with the remote before retrying, and reuse an existing open pull request from the task branch.
- **Clearer constellations:** readable task names and ownership labels help you follow the work, while folded subtask groups preserve card positions and keep tasks needing attention visible.
- **Next to review:** jump to the next permission decision, question or other attention item across open sessions with the header action or Command+J / Ctrl+J.

## Update or install

Use Check for Updates in the macOS Lascoria menu, or Settings → Updates on any supported platform. Installing the update pauses active work and retains saved checkpoints. Interrupted commands require an explicit follow-up.

Mac versions 0.1.2 and 0.1.3 need one manual installer upgrade. Pause work and quit Lascoria safely before replacing the app.

## Compatibility

One universal macOS download supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64/ARM64 packages are also available. This version uses Muse 1.4.14.

Delivery controls operate in isolated task worktrees. Git uses your existing credentials, and creating GitHub pull requests requires the GitHub CLI to be installed and signed in. Push and pull request creation each require your confirmation. Resolve merge conflicts with your Git client. Commits keep repository hooks and signing disabled, so repositories requiring them or Git filters such as LFS should use their own Git client for delivery.

A passing check describes the working-tree files it ran against. If edits remain unstaged, the commit preview explains that those edits were also present during the check.

Windows installers have no publisher certificate, so Windows may display an unknown-publisher warning or block installation under managed policies. Updater signatures remain mandatory. Do not disable protection to install Lascoria.
