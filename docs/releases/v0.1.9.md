# Lascoria v0.1.9: See activity and control session access

See when agents are working and change session settings directly from the workspace header.

- **Visible activity:** moving activity bars identify working tasks and helper agents, with clear waiting states and reduced-motion support. They indicate activity, not a completion percentage.
- **Session controls:** open model and reasoning-effort settings from the header, even with the task inspector collapsed.
- **Permission profiles:** choose Ask me, Auto-review or Read-only when Muse makes them available, review changes before applying them and save a separate default for future sessions.
- **Capability checks:** ask Muse to check its current sandbox boundary and see results verified against native command output.
- **Clearer cards:** long task titles use a clean two-line ellipsis.
- **Muse compatibility:** upgrade the tested Muse runtime and official SDK to stable 1.4.14, including verified installation metadata.

## Update or install

Use Check for Updates in the macOS Lascoria menu, or Settings → Updates on any supported platform. You can also download the installer for your platform from this release. Installing the update pauses active work and retains saved checkpoints; interrupted commands are not automatically replayed.

Mac versions 0.1.2 and 0.1.3 need one manual installer upgrade because those versions reject the universal update filename. Pause work and quit Lascoria safely before replacing the app.

## Compatibility

One universal macOS download supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64/ARM64 packages are also available.

This version uses Muse 1.4.14. Newer Muse permission records may not be readable by older versions; back up retained sessions before upgrading and avoid opening their newer records with an older Muse runtime. Profile changes do not remove existing saved allowances. Sandbox support and capability-check results depend on the operating system and native Muse runtime.

Windows installers have no publisher certificate, so Windows may show an unknown-publisher warning or block installation under managed policies. Updater signatures remain mandatory. Do not disable protection to install Lascoria.
