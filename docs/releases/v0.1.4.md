# Lascoria v0.1.4: Easier updates

Check for updates directly from the macOS Lascoria menu, review the new version in a focused dialog, and install when you are ready.

- **Mac update fix:** the updater now accepts the universal package for both Apple Silicon and Intel.
- **Quiet checks:** automatic checks run every six hours without opening a dialog or downloading an update.
- **Update when ready:** a toolbar button keeps an available update within reach, and dismissing the dialog retains a verified download.
- **Clear controls:** update preferences stay in Settings, with an accessible automatic-check switch and clear failure feedback.
- **Dependency fix:** includes the patched version of a transitive Rust cryptography dependency.

## Update or install

On macOS 0.1.2 or 0.1.3, download the universal installer from the [release page](https://github.com/kabudu/lascoria/releases/latest). Those versions reject the universal update filename, so one manual installation is needed to receive this fix. Pause work and quit Lascoria safely before replacing the app.

Other supported installations can use Settings → Updates, or download their platform installer from the release page. Installing an update pauses active work and retains saved checkpoints; interrupted commands are not automatically replayed.

## Compatibility

One universal macOS download supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64/ARM64 packages are also available.

Windows installers have no publisher certificate, so Windows may show an unknown-publisher warning or block installation under managed policies. Updater signatures remain mandatory. Do not disable protection to install Lascoria.

See the [support guide](https://github.com/kabudu/lascoria/blob/master/SUPPORT.md) for help.
