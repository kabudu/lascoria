# Lascoria v0.5.0: Deliver parallel work with confidence

Keep parallel Muse sessions moving from one workspace. See what needs review, pass evidence between tasks, spot overlapping edits, and bring a blocked pull request back into the delivery flow.

- **See pull request status on the canvas.** Spot pending checks, review requests and merge conflicts on the task that owns the pull request.
- **Hand off evidence between sessions.** Preview a captured diff excerpt, test result or decision, then add it to the receiving draft after Lascoria verifies the source revision.
- **Catch overlapping edits early.** See when isolated tasks change the same file in one repository and jump to the other task from Workspace.
- **Update a pull request safely.** Preview the incoming base, resolve or abort the merge in the isolated worktree, and run fresh checks before pushing.

## Update or install

Use Check for Updates in the macOS Lascoria menu or Settings → Updates on any supported platform. Pause active work before updating.

## Compatibility

The universal macOS package supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64 and ARM64 packages are available. Windows installers may be restricted by security policies because they lack a publisher certificate. Updater packages carry signatures.

Pull request status and base updates use your GitHub CLI sign-in. Base updates run in isolated task worktrees with pull requests from the same repository.
