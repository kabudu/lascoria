# Lascoria v0.6.0: Take a project from plan to review

Project Mission brings the plan, active work and delivery checks together on one canvas. Open a saved project and choose Project Mission to see which tasks can start, which depend on changed work, and where Muse needs your input.

- **Plan work across sessions.** Set a project goal, assign tasks to Muse sessions, and connect tasks that depend on one another.
- **Keep evidence current.** Accept a task's results before starting dependent work. When an upstream result changes, Lascoria shows which tasks need another look.
- **Rehearse changes safely.** Combine selected commits in a separate worktree, resolve conflicts, and test the combined changes before they leave your machine.
- **Get an independent review.** Send the exact tested diff to a separate, read-only Muse session and route findings to the task that owns them. Delivery requires a current, accepted review.
- **Keep the canvas usable in smaller windows.** The mission map and inspector stack, and the canvas toolbar clears the inspector header when collapsed or expanded.

## Update or install

Use Check for Updates in the macOS Lascoria menu or Settings → Updates on any supported platform. Pause active work before updating.

## Compatibility

The universal macOS package supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64 and ARM64 packages are available. Windows security policies may restrict installers that lack a publisher certificate. Updater packages carry signatures.

Use a saved project with isolated sessions for integration and review. A rehearsal combines commits from one repository at a time.
