# Lascoria v0.1.3: Clearer controls

Lascoria’s task inspector is easier to read, preference controls stay aligned, and session archiving is easier to find.

- **Aligned controls:** switch labels stay centred, including long session names that wrap onto multiple lines.
- **Consistent switches:** notification preferences, transcript background activity and the canvas runtime filter share the same control styling.
- **Keyboard access:** switches support keyboard activation, visible focus and saved preferences in both light and dark themes.

- **Readable token use:** see session and task totals beside a context meter, with detailed counts available on demand.
- **Discoverable archiving:** archive the selected session directly from the Sessions panel, without opening a task’s Workspace tab.

## Update or install

Use Settings → Updates in Lascoria, or download the installer for your platform from the [release page](https://github.com/kabudu/lascoria/releases/latest). Updates pause active work and retain saved checkpoints.

## Compatibility

macOS 13.5 or later is required. One universal macOS download supports Apple Silicon and Intel. Windows x64 and Linux x64/ARM64 packages are also available.

Windows installers have no publisher certificate, so Windows may show an unknown-publisher warning or block installation under managed policies. Updater signatures remain mandatory. Do not disable protection to install Lascoria.

See the [changelog](https://github.com/kabudu/lascoria/blob/master/CHANGELOG.md) and [support guide](https://github.com/kabudu/lascoria/blob/master/SUPPORT.md) for details.
