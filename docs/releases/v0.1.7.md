# Lascoria v0.1.7: Keep archived work out of view

Archiving now clears saved work from the canvas and inspector when Show archived sessions is off.

- **Consistent visibility:** the Sessions list, canvas and inspector follow the same archive filter.
- **Keep working:** archiving the selected session switches to unarchived work when available.
- **Clear empty state:** when all sessions are archived, the canvas clears and shows how to revisit history or start a new session.
- **History retained:** reveal archived sessions, use history search or choose View archive to inspect saved work read-only.

## Update or install

Use Check for Updates in the macOS Lascoria menu, or Settings → Updates on any supported platform. You can also download the installer for your platform from this release. Installing the app update pauses active work and retains saved checkpoints; interrupted commands are not automatically replayed.

Mac versions 0.1.2 and 0.1.3 need one manual installer upgrade because those versions reject the universal update filename. Pause work and quit Lascoria safely before replacing the app.

## Compatibility

One universal macOS download supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64/ARM64 packages are also available.

Windows installers have no publisher certificate, so Windows may show an unknown-publisher warning or block installation under managed policies. Updater signatures remain mandatory. Do not disable protection to install Lascoria.
