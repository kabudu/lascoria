# Lascoria v0.2.0: Stage and commit exactly what you choose

Choose which changes go into a commit, down to individual hunks, without leaving Lascoria.

- **Selective staging:** in an isolated task's Workspace tab, stage or unstage whole files or single hunks. Hunk detail stays collapsed until you open it, and the canvas is unchanged.
- **Exact commits:** preview the exact staged content before committing. Only the staged index is committed; unselected edits and new files stay in the worktree.
- **Safe with other tools:** if Muse, an editor or another Git client changes files or the index after the list loaded, the action is refused with nothing changed and the list refreshes. Another process's Git lock is never removed.
- **Unchanged boundaries:** commits never push and do not run repository hooks or commit signing. Sessions working directly in your own checkout keep using your Git client.

## Update or install

Use Check for Updates in the macOS Lascoria menu, or Settings → Updates on any supported platform. You can also download the installer for your platform from this release. Installing the update pauses active work and retains saved checkpoints; interrupted commands are not automatically replayed.

Mac versions 0.1.2 and 0.1.3 need one manual installer upgrade because those versions reject the universal update filename. Pause work and quit Lascoria safely before replacing the app.

## Compatibility

One universal macOS download supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64/ARM64 packages are also available. This version uses Muse 1.4.14, unchanged from 0.1.9.

Staging works in isolated task worktrees only. New, deleted, binary, permission-changed and submodule files are staged whole; renames appear as a removed and a new file; merge conflicts pause staging. Repositories that need hooks, signing or Git filters such as LFS should be committed with your own Git client.

Windows installers have no publisher certificate, so Windows may show an unknown-publisher warning or block installation under managed policies. Updater signatures remain mandatory. Do not disable protection to install Lascoria.
