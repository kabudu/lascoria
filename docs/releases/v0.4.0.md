# Lascoria v0.4.0: Follow pull requests through review

See which GitHub checks failed or which pull requests need changes, then bring the relevant feedback back to the Muse session that did the work.

- **Follow your pull request:** see GitHub checks and review status in Workspace. Failed checks and requests for changes appear in Attention, and results from earlier commits stay available for reference.
- **Bring feedback back to Muse:** preview a failed check or file review comment and add it to the original session draft when you’re ready.
- **Act on blocking decisions:** open Needs your input to answer a question or review the exact permission Muse requested.
- **Control local agent messaging:** Muse Code 1.4.25 asks you to trust the displayed workspace before loading its relay tools. Trust lasts for that Muse host and can be revoked. Each connected pair still needs permission to exchange agent messages. You can share messages manually in any session, including multi-folder Projects.

## Update or install

Use Check for Updates in the macOS Lascoria menu or Settings → Updates on any supported platform. Pause active work before updating. Back up important sessions before upgrading Muse, since an older Muse version may be unable to read newer session records.

## Compatibility

The universal macOS package supports Apple Silicon and Intel on macOS 13.5 or later. Windows x64 and Linux x64 and ARM64 packages are available. Windows installers lack a publisher certificate and may be restricted by Windows security policies. Updater packages carry signatures.

GitHub pull request follow-through uses your existing GitHub CLI sign-in. Workspace trust for Muse messaging is available for idle standalone sessions after their first task has finished.
